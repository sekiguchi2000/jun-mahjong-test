# 音声アセットのライセンスと由来

このディレクトリの `voice/**/` に含まれる `*-v1.wav` は、ローカルの
VOICEVOX Engine 0.25.2 を用いて本作品専用に生成した音声です。音声モデルや
VOICEVOX Engineそのものは製品へ同梱せず、生成済みWAVだけを収録します。

ゲーム内クレジットおよび配布ページには、次を省略せず表示します。

- 半蔵: `VOICEVOX:麒ヶ島宗麟`
- ジョー: `VOICEVOX:玄野武宏(CV:ガロ)`
- ひめ子: `VOICEVOX:冥鳴ひまり`

確認した規約（2026-08-10）:

- VOICEVOX ソフトウェア利用規約: https://voicevox.hiroshiba.jp/term/
- VirVox Project VOICEVOX利用規約: https://www.virvoxproject.com/voicevox%E3%81%AE%E5%88%A9%E7%94%A8%E8%A6%8F%E7%B4%84
- 冥鳴ひまり VOICEVOX利用規約: https://www.meimeihimari.com/terms-of-use

いずれも規約上のクレジットを条件に商用利用可能です。青山龍星のように
別途申請を要する音源は採用していません。将来音声を差し替える場合は、
既存WAVを上書きせず新しい版名で生成し、規約を再確認します。
