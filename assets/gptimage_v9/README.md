## Shared art contract

- References: `gptimage_v1/hanzou_portrait_v1.png`, `joe_portrait_v1.png`, `himeko_portrait_v1.png`
- 1024×1536 vertical chest-up portrait, frontal eye-level gaze
- cinematic semi-photorealistic game key art with visible skin/fabric texture
- dark jewel-tone mineral-plaster background, restrained antique-gold arcs, warm key and rim light
- safe for the production `background-position: center 22%` square crop and circular CSS mask
- original fictional identity; no text, logo, watermark, celebrity likeness, mahjong props, or baked-in frame
